# A privacy-preserving, AI-powered threat detection framework for IoMT medical devices using Federated Learning
Medical devices such as patient monitors, ECG machines, pulse oximeters, infusion pumps, and other Internet of Medical Things (IoMT) devices are increasingly connected to healthcare networks. While this connectivity enables real-time patient monitoring and efficient healthcare services, it also exposes medical devices to cybersecurity threats such as unauthorized access, data tampering, spoofing, malware, and Denial-of-Service (DoS) attacks.

This project aims to develop an AI-powered cybersecurity framework for detecting, identifying, and analyzing potential threats targeting connected medical devices using Federated Learning (FL).
The framework analyzes medical-device network traffic and activity patterns to identify suspicious behavior, detect potential cyberattacks, classify threats, and generate security insights. It can also provide explanations of detected incidents and recommend appropriate security responses.
